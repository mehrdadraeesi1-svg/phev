# Engine maps (not distributed)

The steady-state engine maps were generated with a commercial simulation package (Simcenter Amesim) and are not redistributed for licensing reasons. They are available from the corresponding author on reasonable request.

Place these files here to run the environment:
`conshot_1.data`, `torque_1.data`, `FMEP_1.data`, `NOxhot_1.data`, `COhot_1.data`, `HChot_1.data`, `CO2hot_1.data`, `O2hot_1.data`, `Texhaust_1.data`, `eq_ratio_1.data`, `heatwall_1.data`, `parthot_1.data`.

The battery maps `OCV.data` and `Rdch.data` belong in `utiles/`, and the Birmingham cycle `vel_power_birmangham_refine.csv` in `data_1s/`.
